# Security policy

SecretBox is intended for personal, self-hosted instances. The server stores ciphertext and limited transfer metadata; protecting the content also depends on the devices that encrypt and decrypt it.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository maintainer. If private vulnerability reporting is enabled for this GitHub repository, use that feature. If it is unavailable, open an issue without technical details and ask for a private contact channel. Do not publish exploit details in a public issue before the maintainer has had a chance to respond.

Do not include real tokens, passphrases, private keys, or sensitive transfer contents in a report.

## Security model

See [the threat model](docs/threat-model.md) for what the system does and does not protect.
