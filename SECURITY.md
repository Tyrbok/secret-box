# Seguridad

Este proyecto está pensado para instancias personales autogestionadas. El servidor almacena ciphertext y metadatos mínimos; la seguridad del contenido depende también de los equipos que cifran y descifran.

Para comunicar una vulnerabilidad, contacta en privado con la persona que mantiene esta copia antes de publicar detalles. No incluyas secretos reales, passphrases ni claves privadas en un informe.

Consulta `docs/threat-model.md` para los límites conocidos del diseño.
